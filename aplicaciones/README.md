# Aplicaciones del curso

Aquí va lo que construyáis los días 3 y 4. Una carpeta por persona, con:

- el código (`.js` del Code Editor o `.py` / `.ipynb` de Python),
- una captura de pantalla,
- cuatro líneas en un `README.md` diciendo qué hace, con qué datos y para quién.

Se añade con un *pull request*, que es el ejercicio del último día.
